# 主窗菜单行为史取证（U-169 零代码轮证词书）

词条 P2-6（docs/巨型类拆分-立项词条.md）切片 B 推进至对话框族首抽（U-168 ModuleEditorRegistry）
后余下半册：initActions 动作族与语言/方案两 setup 槽。本轮在动它们之前，把已量出的行为史怪点
以证词入册。所有行位以 U-168 收口提交（fe4f775）后的 src/MainWindow.cpp 现态为准，行位写成
「第 N 行」形式（源行引据名册冻结口径，本块一行都不喂进那份清单的分母）。

## 一、actionNew 双连（触发一次、槽两跑）

铁证两行（src/MainWindow.cpp 第 999 行与第 3844 行）：

    connect(ui->actionNew, &QAction::triggered, this, &MainWindow::onNewProject);

initActions 内（第 999 行）与 setupSchemeMenu 内（第 3844 行）各一条，同动作同槽。两函数都在
构造体无条件调用（src/MainWindow.cpp 第 533 行与其后第 560 行，且前者先调），两连接永存。
QObject::connect 不对同对信号-槽去重：actionNew 每次触发 emits 一次，两槽按连接顺序各跑一遍
——「新建方案」整个路径走两次。onNewProject 首行即 discard 确认（src/MainWindow.cpp 第 1784
行），本体无防重入、无幂等卫：第二跑发生在第一跑完整重建之后的现态上，确认框是否再现由当时
的未保存脏位决定（干净态直接放行，脏态连弹）。摘除或折叠任何一条连接都是**行为变更主张**，
必须走红绿臂 + 变更声明独立轮，抽线轮不得顺手去重。

## 二、语言三源（两枚并存菜单 + 一枚死槽）

### 源一 · I18n 重启链（initActions 自建菜单，src/MainWindow.cpp 第 1114 至 1130 行）

构造期建独立 QMenu「语言」（menubar 另挂，第 1128-1129 行），actZh/actEn 指向 switchLanguage：

- switchLanguage（src/MainWindow.cpp 第 2205 至 2219 行）语义：同语短路；I18n::setLanguage 写
  全局态；弹「语言设置将在重启后生效」；startDetached 重启自身 + quit。**整链不接触
  m_currentLanguage 与 retranslateUi。**

### 源二 · m_currentLanguage 就地链（Designer 菜单，setupLanguageMenu 第 3810 至 3832 行）

表单 menuLanguage（ui/MainWindow.ui 第 210-216 行，含 checkable 的 actionChinese/actionEnglish
同文件第 269-284 行）经 ctor 第 555 行调用本函数接线：

- 回调（src/MainWindow.cpp 第 3816 至 3828 行）写 m_currentLanguage + 双方互斥 checked +
  updateLanguage()（src/MainWindow.cpp 第 4106 至 4111 行，一跳进 retranslateUi，第 4113 行起）
  就地换文。**整链不接触 I18n::setLanguage，不重启。**
- ctor 第 580-586 行另有一发默认 enforce（置中文 + updateLanguage）。

### 源三 · onSwitchLanguage 死槽（src/MainWindow.cpp 第 3007 至 3011 行）

体仅 `logMessage("切换语言")`。死判据三条全齐：全仓无手动 connect（只有 include/MainWindow.h
第 86 行声明与 src/MainWindow.cpp 第 3007 行定义的 grep 双命中）；表单无名叫 SwitchLanguage
的对象（ui 全文 grep 空）；槽名不合 `on_<对象名>_<信号>` auto-connect 约定（无中间下划线，
connectSlotsByName 不认）。不删不接，另行拍板才动。

m_currentLanguage 写用位清单：写 src/MainWindow.cpp 第 152 行（ctor 初值）、第 581 行（默认
enforce）、第 3817 与 3824 行（Designer 回调）；用第 1434 行（标签三元）、include/MainWindow.h
第 306 行（成员）。

**两链互不知晓**：重启链切完语言重启，冒险点是重启后 Designer 菜单回中文默认（m_currentLanguage
不持久）；就地链切完只换主窗文本，I18n 全局态与重启后的翻译态可能跨界不一致。两链合并 /
改语义都属行为变更主张，另轮另判。

## 三、共槽别名与悬空动作对（setupSchemeMenu 第 3834 至 3855 行）

- 保存别名：actionSaveScheme（第 3840 行）+ actionSave（第 3845 行）→ onSaveProject。同槽
  不同动作，合法。
- 打开别名：actionOpenScheme（第 3841 行）+ actionLoad（第 3846 行）→ onLoadProject。同上。
- retranslateUi 给两组动作同文（保存方案/打开方案），别名系刻意，不折叠。
- 悬空动作对：ui「文件」菜单（ui/MainWindow.ui 第 146-155 行）只挂 actionNew / actionOpenScheme /
  actionSaveScheme / actionExit；工具栏只加 actionOpenScheme / actionSaveScheme
  （src/MainWindow.cpp 第 325-326 行）。**actionSave 与 actionLoad 两动作全表单无 addaction
  挂载**——连接常在（src/MainWindow.cpp 第 3845 与 3846 行）但无任何 UI 入口可达，属「接线
  悬空动作对」。同样不删不折，另行拍板。
- 其余单连：actionExit（第 3847 行）→ onExit、actionAddFlow（第 3850 行）→ onAddFlowTab、
  actionDeleteFlow（第 3851-3854 行）→ lambda（闭包取 flowTabs 当前 index，当下快照语义）。

## 四、对下一步抽取的拍板边界（切片 B 余半）

1. 抽 setupSchemeMenu / setupLanguageMenu / initActions 的任何动作接线时：连接条数、连接顺序、
   duplicate 连接一律原样迁，双连不打折；切槽变体（&MainWindow::槽 vs lambda 闭包快照）不换形。
2. 语言两链与 onSwitchLanguage 与悬空动作对各自独立拍板；合并、删除、补挂载均为行为变更。
3. m_currentLanguage 与 I18n::currentLanguage 的双态并存是对既成事实的登记，不是待修缺陷声明。

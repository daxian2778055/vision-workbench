- 判据：行为零变更；testGraphSnapshotDefersDeletionDuringRound 家族续绿；新类纯逻辑腿座须同时入 CMake 注册与 VFP_TESTS 批注列；三件套与宿主整轮。

1. 锁序只许图锁→purge 叶子锁方向，反向即死锁环（代码注释在案）；

3. 停稳判定语义不变（executionParked 才算可改图依据，头内 162..164 行注释口径）；
4. 新增测试座双注册（CMake 与 VFP_TESTS），缺后者启动即崩；
5. ctest 内跑不直跑 exe；宿主整轮收口；附表落笔纪律照用。

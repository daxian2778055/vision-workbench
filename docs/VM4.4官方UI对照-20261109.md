## 1. 通信管理（手册 5.2 / 截图 1）

### 1.1 官方窗口结构

| 区域 | 官方 | 当前实现 | 判定 |
|---|---|---|---|
| 标题栏 | 「通信管理」+ 帮助(?) + **导入/导出 gtd 文件**（右上） | 有管理器窗口；导入导出能力待核 | ⚠️ |
| 左侧导航 | **6 项**：设备管理 / 接收事件 / 发送事件 / **触发配置**（全局触发）/ **响应配置** / 心跳管理 | 管理器含设备管理+接收事件+发送事件+心跳；触发配置、响应配置为独立入口 | ⚠️ 结构不一致 |
| 左上 | 「通信设备列表」+ 虚线 `+`；列表项「序号 名称」+ 右侧启用开关；右键重命名/删除 | 有设备列表与启用开关 | ✅ |

| 右上「通信参数」 | 目标IP(4 段) / 目标端口 / **数据上传**(开关) / **自动重连**(开关) / **接收结束符**(开关，启用后可选 `\r`/`\n`/`\r\n`/自定义) | 有 IP/端口/自动重连；数据上传、接收结束符待核 | ⚠️ |
| 右下 | Tab「接收数据 / 发送数据」+ 大数据区；「16进制显示」复选框 +「清空」；发送数据处可输入并点「发送」 | 有监视器对话框（Hex/ASCII、计数、节流），但**不在同一窗口内** | ⚠️ 结构不一致 |
| 全局配置导出 | 右上角以 **gtd 格式**导入/导出全部通信配置 | 配置随 `.vfp` 方案 JSON 持久化 | ❌ 格式不同 |

### 1.2 官方协议全集（表 5-1，手册页 81–83）

TCP 客户端 / TCP 服务端 / UDP / 串口 / 汇川 H2U / 基恩士 KV / 松下 MewTocol /
三菱 MC / 三菱 FX / **ModBus** / EtherNet/IP CIP / **欧姆龙 Fins TCP** / 欧姆龙 Fins UDP /
欧姆龙 HostLink / 横河 PClink / 西门子 S7 / 西门子 S7-200Smart。

- 第一类 PLC（含 **Fins TCP/UDP**、ModBus、三菱 MC/FX 等）共享「寄存器地址空间」配置：
  首地址 / 寄存器个数 / 添加地址 / 数据同步 / 发送测试 / 最大化 / 隐藏空白行 / 清空。
- 表 5-2 给出各协议支持的通信方式；**欧姆龙 Fins TCP 支持 TcpClient 与 UDP**，Fins UDP 只支持 UDP。
- `OmronFinsTcpModuleParam.xml` 实测：`TargetIP=127.0.0.1`、`TargetPort=7920`
  —— 与截图 1 的「目标端口 7920」完全一致，说明官方默认值即如此。

**用户已定口径**：不新增协议；FINS 是唯一将来可能加的，且应按官方拆成 TCP/UDP 两种。

### 1.3 通信管理结论

**UI 结构 ≈ 六成**：6 个功能域能力都有（散在不同对话框），但**窗口形态不是 1:1**——
缺「控制器列表」、右下收发监视未并入主窗口、无 gtd 导入导出、左侧导航只覆盖 4/6 项。

## 2. 运行界面设计（手册第 9 章 / 截图 2）

### 2.1 官方四区域（9.1，页 181）

| 区域 | 官方职责 | 当前实现 |
|---|---|---|
| 工具条 | 保存、模板设置、图层设置、删除、固定栏设置、导出 | 有工具条但项数不足 |
| 控件区 | 分组呈现可用控件 | 有控件库，但分组/项数不足 |
| 预览及编辑区 | 呈现当前设计中的运行界面；可绘制/编辑控件 | 有固定 1200×760 画布 |
| 属性设置区 | 展示**画布 / 固定栏 / 控件**三类的属性（布局、数据源、颜色、字体） | 有属性面板但字段少 |

### 2.2 官方工具条全 15 项（页 182）

1. 加载已保存的运行界面
2. 保存（首次需选路径）
3. **选择已保存的模板**应用/删除
4. **另存为模板**（名称 / 创建人 / 推荐使用场景 / 描述）
5. 图层位置 4 档：**顶层 / 上一层 / 底层 / 下一层**
6. 多选对齐 6 种：左 / 水平居中 / 右 / 顶部 / 垂直居中 / 底部（≥2 个）
7. 分布 2 种：水平 / 垂直（**≥3 个**）
8. 撤销
9. 重做
10. 删除
11. **运行界面窗口相对编辑区按比例适配大小**（打开时默认调用一次）
12. 缩放滑块（截图 2 显示 69%）
13. **固定栏设置**：上 / 下 / 左 / 右（可多选）
14. 预览
15. 导出（方案 + 运行界面一起打成工程包）

> 右键菜单支持：删除、撤销、重做、图层位置。
> 复制粘贴**仅** `Ctrl+C` / `Ctrl+V`。
> 工具条部分功能仅型号带 6210 / 7120 的加密狗可用。

**当前实现**：图层只有「上移/下移一层」2 档；对齐 4 种（左/顶/横均分/纵均分）；
有撤销/重做但**不覆盖属性与几何编辑**；`Ctrl+D` 复制且**无粘贴**；
有缩放滑块？有预览；**无固定栏设置、无模板、无导出、无适配按钮**。

### 2.4 官方控件属性（9.3，页 189+；第三张实机截图为选中「图像」控件时的面板）

手册文字写「参数分为数据源、布局、外观三大类」，但**实机截图显示是 4 个可折叠分组**
（每组右侧有 ∨ 折叠箭头，可同时展开），以截图为准：

| 分组 | 官方字段（截图 + 9.3） |
|---|---|
| **标识** | 类型（只读，如「图像」） |
| **数据源** | 数据源（输入框 + `...` 配置 + `X` 清除）、图形配置、叠加图层 1/2/3、**保留上一次结果**（开关） |
| **布局** | **自动填充**（开关）、**尺寸**（W × H 两个数值框，截图 1278 × 627）、**边距**（T/B/L/R 四数值 + 一键同步）、**对齐方式**（垂直 3 种 × 水平 3 种的九宫格按钮） |
| **外观** | 显示工具栏（开关）、按钮/边框/图标颜色、字体、圆角半径、OK/NG 两态配色 |

按钮控件的属性（第四、五张实机截图）：

| 分组 | 按钮的官方字段 |
|---|---|
| 标识 | 类型（只读「按钮」） |
| 数据源 | **只有「配置」按钮**（不是输入框）→ 弹「数据源配置」对话框 |
| 布局 | 自动填充、尺寸 100×40、边距 T=304/L=521、九宫格对齐 |
| 外观 | **显示文本**（「按钮」）、**字体**（大小 12 · 字形加粗）、**字体颜色** `#FFE6E6E6`、**背景** `#FF565657`、**边框颜色** `#FF272727`、**点击颜色** `#FF769000` |

「数据源配置」弹窗（第五张截图）：一张动作表，列为
**触发命令类型 | 方法 | 输入参数**，行尾有删除 `X`，底部「确定」。
触发命令类型下拉为 **界面链接 / 参数配置 / 方案 / 执行 / 重置** 五项。

> 对照：当前按钮只有 `bindType="action"` + `bindKey`（单字符串，4 种动作：
> 开始执行/停止执行/单次执行/触发流程），且外观只有「颜色 + 字号 + 可见」。
> **动作表（多行 / 类型+方法+参数）属于持久化结构变更，记 B2**；
> 本轮（B1c）只补外观字段。

画布本身也有属性（第二张截图右侧「基础设置 / 外观」）：
显示网格、网格颜色（`#FF1E1E1E`）、背景（`#FF383838`）。

当前属性面板是 `QFormLayout` 平铺，字段只有：标题、类型、绑定方式、绑定对象、颜色、字号、
可见性、新列来源、已有列、最大行数。**无分组、无自动填充、无 T/B/L/R 边距、无九宫格对齐、
无画布属性**。

> B1 只把面板**分组结构**对齐（标识/数据源/布局/外观四组），布局组的 T/B/L/R、
> 自动填充、九宫格对齐与画布属性要扩展 `RuntimeControl` 模型，归 **B2**。

### 2.5 官方交互（9.2.2，页 183）

> 「在左侧控件区通过鼠标选中某个控件后，**按住鼠标左键不动并移动到中间的预览及编辑区**，
> 在计划摆放控件的区域松开鼠标即可完成控件添加。」

当前实现**不支持控件库→画布拖放**（全文件无 `QDrag`/`dropEvent`），只有「选中 + 添加按钮 / 双击」。
项目手册 `docs/用户操作手册.md:45,494` 写的「拖拽式搭建」指的是画布内拖动，**与官方口径不符**。

### 2.6 画布与固定栏（9.3.1）

- 画布默认单画面；选中画布可在属性区配置**基础配置 + 布局分割样式**（模板1 等）
- 固定栏上/下/左/右可多选；每个固定栏有自己的**分割模板**
- 控件拖到固定栏或画布的网格里；控件「自动填充」= 填满所在网格

当前：画布固定 1200×760、**无分割样式**、**无固定栏**、**无网格单元格概念**。
截图 2 右侧属性区的「外观 / 显示网格 / 网格颜色 / 背景」正是**画布属性**，当前无对应。

### 2.7 运行界面结论

**UI 结构 ≈ 三成**：四区域骨架在，但工具条缺 9 项、控件少 15 种、
无拖放 / 无 Ctrl+C/V / 无固定栏 / 无画布分割 / 无模板 / 属性区字段远少于官方。

## 3. 分阶段实施顺序（用户口径：先 UI 一致，功能后补）

| 批次 | 内容 | 风险 |
|---|---|---|
| **B1（本批）** | 设计器**骨架**：工具条补齐（图层 4 档、对齐 6+2、适配按钮、固定栏入口占位、模板入口占位）、控件区按官方三组分组并补齐控件名占位、属性区按「数据源/布局/外观」三折叠分组、**控件库→画布拖放**、**Ctrl+C/V**、撤销栈覆盖属性与几何 | 中：只动设计器 UI，模型/持久化兼容旧布局 |
| B2 | 固定栏（上/下/左/右）+ 画布分割模板 + 网格单元格 + 自动填充 / T/B/L/R 边距 / 九宫格对齐 | 高：影响布局模型与运行视图 |
| B3 | 控件逐个补实现（按现场需要的优先：参数设置、开关控制、Tab页、组合框、线图/饼图） | 中：每种都要绑数据 |
| B4 | 通信管理窗口形态对齐：6 项左导航合并入口、控制器列表、右下收发监视并入、gtd 导入导出 | 中 |
| B5（可选） | FINS TCP/UDP 协议（官方参数见 1.2） | 高：需真机 |

**原则**：每批只动一层，模型与持久化保持向后兼容（旧布局能加载），每批配腿 + 全量回归 + 出包。

### B1a 已落地（2026-11-09，本轮）

先做了两处**官方明确、且不改布局模型/持久化**的交互：

1. **控件库 → 画布拖放**（官方 9.2.2「按住左键移动到预览及编辑区松开」）：
   `m_palette` 开 `dragEnabled + DragOnly`、item 补 `ItemIsDragEnabled`；
   `RuntimeDesignerCanvas` 开 `setAcceptDrops(true)` 并重写 `dragEnterEvent/dropEvent`，
   只收 Qt 内建 item-model MIME（不解析私有格式），落点经钳制后作为控件左上角。
   原有「添加按钮 / 双击」两条路径保留。
2. **Ctrl+C / Ctrl+V 复制粘贴**（官方 9.1 工具条注「复制粘贴仅支持 Ctrl+C 和 Ctrl+V」）：
   剪贴板放单控件的 `RuntimeInterfacePage::toJson()`（自定义 MIME
   `application/x-vfp-runtime-control`），粘贴时 `fromJson()` 还原并级联偏移 24px、入撤销栈。
   焦点在输入框内时经 `FocusGuard` 让位给文本编辑，不抢输入框的复制粘贴。
   `Ctrl+D` 原位级联复制保留。

腿 `UiGuardsTest::runtimeDesignerHasOfficialDragAndClipboard`（18 passed）锁住三条结构性事实：
控件库 `dragEnabled + DragOnly`、画布 `acceptDrops()`、两个快捷键都在。

### B1b 已落地（2026-11-09，第三张实机截图后）

- **属性区四分组**：从 `QFormLayout` 平铺改为 `标识 / 数据源 / 布局 / 外观` 四个
  `QGroupBox`（放进 `QScrollArea`），与实机截图一致（手册文字写「三大类」，以截图为准）。
  布局组给出只读「尺寸 / 位置」（拖动、拖放后实时刷新），并明示
  自动填充 / T·B·L·R 边距 / 九宫格对齐待 B2 模型扩展。
- **对齐**：`AlignMode` 从 4 种扩到官方 **6 种对齐**（左 / 水平居中 / 右 / 顶 / 垂直居中 / 底）
  + **2 种分布**（水平 / 垂直，≥3 个才生效），统一以「选中控件组成的区域」为基准。
  工具条 4 个对齐按钮扩为 8 个。
- **图层**：从「上移/下移一层」2 档扩到官方 **4 档**（置于顶层 / 上移一层 / 下移一层 / 置于底层）。

腿 `UiGuardsTest::runtimeDesignerHasOfficialSectionsAndAlign`（四分组、8 个对齐/分布按钮、
4 个图层档位）与 `runtimeDesignerAlignHCenterAndRight`（水平居中 / 右对齐的几何行为）；
`UiGuardsTest` 共 **20 passed**。

### B1c 已落地（2026-11-09）

- **按钮外观字段**：`RuntimeControl` 增 `bold / bgColor / borderColor / pressedColor`，
  序列化**只在非默认时写出**、读取用默认值 ⇒ 旧布局外观零变化；设计器外观组补
  显示文本 / 字体（字号+加粗）/ 字体颜色 / 背景 / 边框颜色 / 点击颜色；运行视图按钮渲染同步消费。
- **控件区按官方分组**：`基础 / 图表 / 其它` 三个组标题（不可选、不可拖），控件条目改用
  `Qt::UserRole` 存枚举类型（不再按行号推断）。只列**已实现**的 7 种，未实现的等 B3 补。
- **模板**：底部「存为模板 / 应用模板」，落盘到 `runtime_templates/*.json`（真实现，非占位）。
- **属性编辑进撤销栈**：600ms 防抖合并，连续输入只留一个撤销点。

`UiGuardsTest` **22 passed**。

**B1 仍未做（需 B2 模型）**：工具条「按比例适配」（要画布尺寸字段）、固定栏上/下/左/右入口
（要固定栏模型）；**几何编辑撤销**（要「改前快照」，属交互层补强）。
这几项都不放灰按钮/假占位，等模型到位再补。

## 〇、必须先纠正的错（我此前的臆断 vs 官方定义）

| 项 | 官方定义（原文摘录） | 我之前的错误实现 | 处置 |
|---|---|---|---|
| **尺度模式** | 「设置**速度尺度**的配置模式，可选自动/手动，默认自动」 | 当成"尺度范围自动估"（按模板占比估 ±30%） | **改**：控制速度尺度的自动/手动 |
| **速度尺度** | 「定义图像金字塔**顶层**的大小…该值越大表示金字塔顶层图像越小，边缘点越稀疏，加快匹配，但过大会漏检。**取值 1~20**」 | 当成"粗搜长边像素"，240..1600 | **改**：1~20，顶层降采样倍率 |
| **特征尺度** | 「图像金字塔**底层**的大小…越大底层搜索图越小、特征点越稀疏、抗形变越强。**不能大于速度尺度**；1 最精细」 | 当成 Sobel 核 3/5/7 | **改**：1~20，底层特征提取步长/降采样 |

| **全部屏蔽** | 「将**已绘制的掩膜全部屏蔽和匹配中心**，此时可通过"刷"的方式绘制 ROI」 | 当成"清空形状" | ✅ 已改：清空形状+匹配中心，进入套索绘制 |

### 3. 运行参数（官方定义）
| VM 项 | 官方定义 | 我们的参数 |
|---|---|---|
| 全部搜索模式 | 逐个使用所有勾选的模板匹配，输出最优（默认关）。**关闭时**：按模板列表顺序优先靠前的模板，找到符合最小匹配分数的目标即停止 | ✅ `matchAllTemplates`：关=按列表顺序逐个试、达标即停；开=全部试完取最高分 |
| 模板排序 | 列表里可上下排序；未开全部搜索模式时按此顺序逐个试 | 未做（列表顺序即匹配顺序） |
| 最小匹配分数 | 相似度阈值 | `minScore` |
| 最大匹配个数 | 允许查找的最大目标数；帮助页：「默认值为 1，有效取值范围为 1~1000」 | ✅ `maxMatches`（注册与运行时 1~1000） |
| 匹配极性 | 边缘到背景的颜色过渡（考虑/不考虑） | `polarity` |
| 角度范围 | 起 ~ 止（+步长） | `angleMin/Max/Step` |
| 尺度范围类型 | **整体**（尺度范围）/ **分别 X、Y 轴**（尺度范围XY） | 未做（等距） |
| 尺度范围 | 起 ~ 止（+步长） | `scaleMin/Max/Step` |
| 最大重叠率 | 两目标重叠率超阈值时舍弃低分目标。**0~100，默认 50** | 未做 |
| 排序类型 | 多目标时「当前结果」的排序依据：**按分数降序 / 按角度降序 / 按X由小到大 / 按Y由小到大 / 按X再Y / 按Y再X** | ✅ `sortType` 0~5（默认按分数降序） |
| 阈值类型 | **自动阈值**（按目标图像生成）/ **模板阈值**（模板阈值经内部转换）/ **手动阈值** | ✅ `thresholdType` 0/1/2 + `matchContrastThreshold`（手动值，灰度差 1~255） |
| 延拓阈值 | 目标被图像边缘截断时，缺失特征相对完整特征的比例 | ✅ `extendThreshold` 0~100：候选窗口被截断时按缺失比例放宽可见率门槛 |
| 超时控制 | 搜索超时时长，**0~10000 ms，0=关闭**；帮助页：「搜索时间达到超时时长算法将停止搜索，**不返回任何搜索结果**」 | ✅ `timeoutMs`：到点停止搜索，不返回任何搜索结果（超时后 matchCount=0、模块判失败并给出原因） |
| 最大重叠率 | 两匹配框重叠超阈值时舍弃低分目标。**0~100，默认 50** | ✅ `maxOverlap`：按 交叠/较小框面积 计，超阈值丢低分 |
| 尺度范围类型 | **整体**（尺度范围）/ **分别 X、Y 轴**（尺度范围XY） | ✅ `scaleRangeType` 0/1 + `scaleMinX/MaxX/MinY/MaxY`；非均匀 warp（R·diag(scaleX,scaleY)） |
| 横切角度范围 | 尺度范围XY 页签下：目标 Y 轴向 X 轴倾斜的剪切角度范围 | ✅ `crossAngleMin/Max`（-45~45，默认 0~0；仅 scaleRangeType=1 参与搜索；warp 为 R·S·H，H=[[1,tanθ],[0,1]]，结果输出「横切值」） |
| 是否获取轮廓 | 开启则显示模板轮廓特征点；关闭则不显示特征点，只显示匹配框，**可降低匹配耗时** | ✅ `getContour`（默认开）：计算模板轮廓点并按命中位姿显示；关闭跳过提取，结果对象不带轮廓，画布只留匹配框 |
| 是否输出轮廓 | 打开则在模块结果中输出轮廓；关闭则不输出 | ✅ `outputContour`（默认关）：打开输出 `matchContourCount` / `matchContourPointXs` / `matchContourPointYs`（依赖「是否获取轮廓」） |

### 4. 结果显示
- **结果判断**：忽略匹配个数 / 数量判断 / 角度判断 / 尺度判断（开关）
- **图像显示**（各带显隐开关 + 样式编辑）：检测区域 / 匹配结果 / 匹配点 / 匹配检出点

## 二、匹配模式

VM 是**两个工具**：高精度匹配（轮廓/特征）与快速匹配（形貌/灰度）。
我们用 `method` 区分（2=高精度，0/1=快速）。**不要把 method 暴露成"算法下拉"**。

## 三、模板配置窗（官方「特征模板」流程）

1. 工具窗「特征模板」→「创建」→ 打开**模板配置**窗（默认显示当前图像源的图，可「选择其他图像」）
2. 顶栏：选择当前图像 / 选择其他图像 / 模板存图（默认开，存模板文件）/ **全部屏蔽**（开关）
3. 工具栏（官方选项表）：
   - 形状：矩形、圆形、多边形（≤32 顶点）、自由绘制
   - **选择匹配中心**（图上取点按钮；锁定后隐藏）✅
   - **锁定匹配中心**（底部勾「锁定」后，「图上取点」按钮隐藏）✅
   - **擦除轮廓点**（单击擦掉该区域特征点，半径 20px；擦掉的点不参与匹配）✅
   - 撤销上一步 / 恢复至撤销前
   - 缩放：放大 / 缩小 / 1:1 / 适应
4. **配置参数**（模板级）：
   | 项 | 官方定义 | 范围 |
   |---|---|---|
   | 尺度模式 | 速度尺度的自动/手动（默认自动） | 自动/手动 |
   | 速度尺度 | 金字塔**顶层**大小，越大越快越易漏检 | **1~20** |
   | 特征尺度 | 金字塔**底层**大小，越大越稀疏/抗形变越强；**≤ 速度尺度**；1 最精细 | 1~20 |
   | 阈值模式 | 对比度调整的自动/手动（默认自动） | 自动/手动 |
   | 对比度阈值 | 特征点与背景的灰度差，越大淘汰越多 | **1~255** |
   | 链长模式 | 最小链长的自动/手动 | 自动/手动 |
   | 最小链长 | 特征链的最小长度，短于此链不保留 | — |
5. 底部：**匹配中心 (x, y) + 锁定 + 确定**

## 五、实现映射（我们没有图像金字塔，用等效手段达到同一效果）

| VM 参数 | VM 实现 | 我们的等效实现 | 默认值策略 |
|---|---|---|---|
| 速度尺度 1~20 | 金字塔顶层大小 | 粗搜降采样倍率 = 速度尺度；「尺度模式=自动」按图像长边/640 取（2~20） | 3 |
| 特征尺度 1~20 | 金字塔底层大小 | 特征点按 step×step 网格稀疏化（1=不稀疏） | 1（不稀疏） |
| 对比度阈值 1~255 | 特征点与背景的灰度差 | Sobel(ksize=3) 幅值阈值 = 灰度差 × 4（阶跃响应 4×） | 5（≈原常量 Sobel 20） |
| 最小链长 | 特征链最短点数 | 边缘二值图连通域面积 < 最小链长的链丢弃 | 1（不过滤） |
| 尺度模式 | 速度尺度的自动/手动 | 同左 | 手动 |
| 链长模式 | 最小链长的自动/手动 | 自动 = 最小链长取 2×特征尺度 | 手动 |

**默认值铁律**：节点/模板默认值取 VM 口径（阈值 5、特征尺度 1、最小链长 1、手动），
建模板时「自动建议」（`suggestParams`）可覆盖；不再为旧工程保持旧默认值（项目未上线，不做兼容）。

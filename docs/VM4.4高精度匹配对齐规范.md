## 二、匹配模式（VM 四模块 vs 本节点覆盖）

VM 4.4 有四个定位模块（帮助页）：高精度匹配（多层金字塔，精度高）、快速匹配（只用金字塔顶层，速度快；**仍是边缘特征法**）、轮廓匹配、灰度匹配（NCC 灰度相关）。

本节点显示名「高精度匹配」，`method` 映射：
- **2 = 高精度匹配**（GOC 边缘梯度；**默认**，与 VM 开箱一致）
- 1 = 灰度匹配（归一化相关系数 NCC）
- 0 = 灰度匹配（归一化平方差）

快速匹配 / 轮廓匹配是 VM 的独立模块，本节点未单列（边界）；不要把快速匹配与灰度法混为一谈。**不要把 method 暴露成"算法下拉"**（保持模板页字段）。

## 三、模板配置窗（官方「特征模板」流程）

1. 工具窗「特征模板」→「创建」→ 打开**模板配置**窗（默认显示当前图像源的图，可「选择其他图像」）
2. 顶栏：选择当前图像 / 选择其他图像 / 模板存图（默认开，存模板文件）/ **全部屏蔽**（开关）
3. 工具栏（官方选项表）：
   - 形状：矩形、圆形、多边形（≤32 顶点）、自由绘制
   - **选择匹配中心**（图上取点按钮；锁定后隐藏）✅
   - **锁定匹配中心**（底部勾「锁定」后，「图上取点」按钮隐藏）✅
   - **擦除轮廓点**（单击擦掉该区域特征点，半径 20px；擦掉的点不参与匹配）✅
   - 撤销上一步 / 恢复至撤销前
   - 缩放：放大 / 缩小 / 1:1 / 适应
4. **配置参数**（模板级）：
   | 项 | 官方定义 | 范围 |
   |---|---|---|
   | 尺度模式 | 速度尺度的自动/手动（默认自动） | 自动/手动 |
   | 速度尺度 | 金字塔**顶层**大小，越大越快越易漏检 | **1~20** |
   | 特征尺度 | 金字塔**底层**大小，越大越稀疏/抗形变越强；**≤ 速度尺度**；1 最精细 | 1~20 |
   | 阈值模式 | 对比度调整的自动/手动（默认自动） | 自动/手动 |
   | 对比度阈值 | 特征点与背景的灰度差，越大淘汰越多 | **1~255** |
   | 链长模式 | 最小链长的自动/手动 | 自动/手动 |
   | 最小链长 | 特征链的最小长度，短于此链不保留 | — |
5. **掩膜列表**：每块保留掩膜一个「增强匹配」勾选（VM：仅高精度匹配支持；开启后该掩膜区域相似度要求更严）。✅ 以掩膜下标 `enhancedShapes` 落库；GOC 评分用该掩膜的局部分数给整体分数封顶（局部不可见/不达标压到 0）；灰度法不参与
6. 底部：**匹配中心 (x, y) + 锁定 + 确定**

## 五、实现映射（我们没有图像金字塔，用等效手段达到同一效果）

| VM 参数 | VM 实现 | 我们的等效实现 | 默认值策略 |
|---|---|---|---|
| 速度尺度 1~20 | 金字塔顶层大小 | 粗搜降采样倍率 = 速度尺度；「尺度模式=自动」按图像长边/640 取（2~20） | 3（手动时用） |
| 特征尺度 1~20 | 金字塔底层大小 | 特征点按 step×step 网格稀疏化（1=不稀疏） | 1（不稀疏） |
| 对比度阈值 1~255 | 特征点与背景的灰度差 | Sobel(ksize=3) 幅值阈值 = 灰度差 × 4（阶跃响应 4×） | 5（≈原常量 Sobel 20） |
| 最小链长 | 特征链最短点数 | 边缘二值图连通域面积 < 最小链长的链丢弃 | 1（不过滤） |
| 尺度模式 | 速度尺度的自动/手动 | 同左；**只作用于速度尺度**，运行参数尺度范围始终只认 `scaleMin/Max/Step`（VM 无搜索尺度自动） | 自动 |
| 链长模式 | 最小链长的自动/手动 | 自动 = 最小链长取 2×特征尺度 | 手动 |

**默认值铁律**：节点/模板默认值取 VM 口径（尺度模式自动、阈值 5、特征尺度 1、最小链长 1、链长模式手动），
建模板时「自动建议」（`suggestParams`）可覆盖；不再为旧工程保持旧默认值（项目未上线，不做兼容）。

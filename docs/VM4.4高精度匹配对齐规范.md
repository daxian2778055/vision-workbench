## 二、匹配模式

VM 是**两个工具**：高精度匹配（轮廓/特征，亚像素、抗遮挡）与快速匹配（灰度/形貌）。
我们用 `method` 区分：2 = 高精度匹配（GOC），0/1 = 快速匹配（平方差/相关系数）。
**不要把 method 暴露成"算法下拉"**——后续应拆成两个工具或一个「匹配模式：高精度/快速」。

## 三、模板配置窗（截图 5）

- 顶栏：选择当前图像 / 选择其他图像 / 模板存图 / 全部屏蔽（开关）
- 工具栏：移动、自由绘制、圆、矩形、多边形（≤32 顶点）、**选择匹配中心**、**生成模型**、**擦除轮廓点**、清空、撤销、重做 + 缩放（放大/缩小/1:1/适应）
- 右：**列表**（形状条目）+ **配置参数**：
  | VM 项 | 我们的参数（每模板） |
  |---|---|
  | 尺度模式（自动/手动） | `TemplateEntry` → `scaleMode`（节点级兜底） |
  | 速度尺度 | `coarseLongSide`（粗搜长边） |
  | 特征尺度 | `aperture`（Sobel 核） |
  | 阈值模式（自动/手动） | `autoThreshold` |
  | 对比度阈值 | `edgeThreshold` |
  | 链长模式（自动/手动） | 未做（与可见率 `minVisibleRatio` 语义不同，勿混用） |
- 底部：**匹配中心 (x, y) + 锁定 + 确定**

## 五、约束（防止再次跑偏）

1. **不发明功能**：VM 没有的（魔术棒/分割/剪刀/链长模式等）一律不加；确需扩展先在本表登记。
2. **命名以本表为准**：新增参数必须先写进本表，再改代码。
3. **分组即页签**：参数的 `ParamSpec.group` 必须取「图像输入 / ROI区域 / 运行参数 / 模板配置 / 结果显示」之一，工具窗按 group 归到四页签。
4. **每项都要有腿**：行为类改动必须带测试或实测数据，记进 `模板匹配进度与交接.md`。

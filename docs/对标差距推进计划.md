### 0.4 引用行号的可复验口径（2026-09-26 阶段 A 的 A7 新增）

该脚本是这 **33** 个锚点唯一的可执行定义：每条 = 一条定位正则 + 文档当前公布的行号；三种失败形态都判 exit 1，**没有静默跳过**——
**DRIFT**（文档被编辑但引用数字没同步，输出直接给出新行号）／**MISSING**（目标句被改写掉，命中 0）／**AMBIGUOUS**（目标不再唯一，命中 >1，常见于把原句抄进台账行时）。

## 7. 执行纪律（沿用路线图 §6 ③-a～③-f，另加自加约束；**A7 于 2026-09-26 追加第 6、7 条 ⇒ 原标题里的“新增两条”已改为不报数**）

1. **能变红才谈绿**：本计划任何一条验收判据，落地时必须给出"故意改坏再重跑变红"的证据（A3/A4/C1 尤其如此）。
2. **口径先落脚本**：凡进文档的统计（如 A5 的 41 文件）只引 `tools/` 脚本输出，脚本 exit 恒 0，不挂 CI 门禁。
3. **归因不得强于证据**：结论分两句写——"我测到了什么 / 我因此怀疑什么"，后者带推测标记。
4. **状态回写要就地**：改了结论的旧文档行**原文保留并标注撤回**，不删除（对齐 ⑲/⑳ 的做法）。
5. **本计划自加**：排除项（§0.1）不得在后续文档中以"缺口"再次出现；引用差距清单时必须连排除说明一起引。
6. **引用行号必须与口径同处改（A7 新增）**：凡引用路线图／SRS 的行号，**唯一权威定义在 `tools/doc_anchors.py`**（33 锚点 = 定位正则 + 公布行号，见 §0.4）。改这两份文档 ⇒ 先跑 `python tools/doc_anchors.py`；报 **DRIFT** 就按它给出的新行号**同时**改正文引用与脚本里的 expect，只改一边下一次必红；报 **AMBIGUOUS** 多半是引用被抄进了台账行，要给正则换一句只出现在正文里的话。**不许把"手工重测出的数字"单独抄进正文当结论**——那只是给漂移拍了张照（本轮 ㉗ 台账行插入的当场，22 个路线图锚点同时变红，见 §1.1「A7」⑤）。
7. **改文档同样在字节层面做（A7 新增）**：改 CRLF 文档只能做**不含换行的定点替换**（或直接在字节上替换）；任何“按标志重拼行尾”的写法必须自带 `lone_cr==0` 断言。理由不是理论——本轮一次这样的写法把整份路线图翻成 `\r\r\n`（277 处 lone CR），**先变红的是 `python tools/doc_anchors.py`（23 个锚点 DRIFT）**，再按字节复核才定位到根因（见 §1.1「A7」⑦）。**另补一条同族坑**：Python 文本模式 `io.open(path).read()` 会把 CRLF **静默折成 LF**，再 `encode()` 写回就等于把整份文档改成 LF——同一处 `lone_cr` 计数断言当场拦下了第二次尝试。⇒ 定型的写法：读**字节** → `decode()`（不翻译换行）→ 只替换不含换行的子串 → 写**字节** → 复核 `cr`/`crlf` 计数不变。

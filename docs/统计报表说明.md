# 统计报表说明（良率 / 趋势 / NG 分布）

入口：主界面菜单 **视图 → 统计报表**。数据来自本地数据库（SQLite，离线可用），不联网、不上传。

---

## 1. 报表能看什么

| 区域 | 内容 |
|---|---|
| KPI | 总记录数、NG 记录数、**总轮次**、OK/NG 轮次、**良率**、数据时间区间 |
| 按天趋势 | 每天的 **OK 轮次 / NG 轮次** 堆叠柱（天数多时只画最近 31 天） |
| NG 按节点分布 | NG 次数最多的 **Top 10 节点**（横向条），用于直接定位"哪个算子最常失败" |
| 筛选 | 时间范围（今天 / 近 7 天 / 近 30 天 / 全部）＋ 流程过滤 |

---

## 2. 良率是怎么算的（**口径**，重要）

**良率 = OK 轮数 ÷ 总轮数**，其中"轮"来自执行器在**每轮结束时自动写入的一条「整轮汇总」记录**
（节点名为 `(整轮汇总)`，通过 = 本轮没有失败节点）。

- 为什么需要它：检测结果默认是"每节点一条"且没有轮次标识，据此只能算出**节点执行通过率**，
  算不出客户真正关心的**良率**；这条汇总记录让良率有可靠口径（每轮多一条记录，开销可忽略）。
- **旧数据没有这条记录**时，报表会明确显示"**无轮次数据**"，而**不会**显示成 0% 良率
  （把"没数据"说成"全部 NG"是更糟的误导）。节点 NG 分布不受影响，仍然可用。
- 数据库默认只保留 **30 天**（可在设置里调整保留天数）；超出范围请在时间范围里选择"近 30 天"。

---

## 3. 导出

| 格式 | 用途 | 特点 |
|---|---|---|
| **CSV** | 交给 Excel 做二次统计 | 带 UTF-8 BOM，Excel 双击即正确显示中文；含汇总/按天/按节点/按流程四段 |
| **HTML** | 存档或发给客户 | **自包含**（无外部资源、无脚本），断网也能打开；内置简易条形图 |
| **PNG** | 贴进报告/邮件 | 按天趋势与 NG 分布两张图上下拼接 |

导出文件名形如 `report_20260923_1030.csv`（自动带时间戳）。

## 4. 良率目标线与报警联动

| 项 | 说明 |
|----|------|
| 设目标 | 报表窗口顶部「良率目标(%)」：**0 = 未设目标**（不画目标线、不判定、运行期也不报警） |
| 目标线 | 画在**「按天良率（%）」**图上（虚线）。为什么单开一张图：上面那张"按天趋势"是**轮次计数**，百分比目标线画在计数轴上没有意义 |
| 达标结论 | KPI 里显示「目标 X% 达标/未达标」，未达标时良率数值**标红**；导出 CSV/HTML 也带上目标与结论 |
| 口径 | 达标判据 `良率 ≥ 目标`（**等于目标算达标**）；"无轮次数据"**不算未达标**（没数据 ≠ 不合格） |

**运行期报警联动**（连续生产时自动盯着）：

- 每轮结束后按**最近 N 轮**（滚动窗口，配置键 `reporting/yieldWindowRounds`，默认 50）算一次良率；
  窗口内**至少 10 轮**才判定——刚开线第一轮 NG 不该报警。
- 良率**低于目标**时报警：写报警历史（**系统 → 报警历史**，级别 `Warning`）+ 运行日志 + 状态栏提示；
- **恢复**到目标线以上时给一条 `Info` 通知（避免"报警了但没人知道什么时候好的"）；
- **同一段低良率只报一次**（闭锁）：恢复到目标线以上才解除，之后再跌破才会再报——
  否则连续模式每轮都报，报警历史会被灌满，等于没有报警；
- 判定节流 5 秒（连续模式每秒可能几十轮，每轮都查库会拖住界面）；
- **数据源与报表完全一致**（同一个库、同一批「整轮汇总」记录）——避免出现"报表看着正常、报警却在响"，
  现场无法解释；
- 目标改了立刻生效（报表里改完即对运行期生效；改目标会重置闭锁并按新口径重新判一次）。
- 不想用：把目标设回 0；或只关运行期报警 → 把 `reporting/yieldTargetPercent` 设为 0
  （目标线也随之消失，因为它们是同一个配置）。

## 5. 常见问题

| 症状 | 处置 |
|---|---|
| 打开报表是空的 | 先确认已启用数据库（设置中的数据库路径非空）；再确认所选时间范围内有运行记录 |
| 显示"无轮次数据" | 该范围内只有升级前的旧数据；重新跑一次流程后即出现良率 |
| 良率与"节点 NG 率"不一致 | 二者口径不同：良率按**轮**，节点分布按**节点**（一轮里可能多个节点 NG，只算一轮 NG） |
| 记录数提示达到上限 | 缩小时间范围或减小数据保留天数（默认上限 20 万条，避免一次性载入过多） |

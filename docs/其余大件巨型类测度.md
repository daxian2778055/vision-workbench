# 其余大件巨型类测度（测度轮）

> 性质：**测度轮**——零代码零行为；把「巨型类拆分」主题从主窗与执行器扩到全仓其余大件，逐件量形并处置（真核候选 / 虚档 / 已收束 / 已立项），只作定序依据。
> 依据：HEAD 态逐件函数全景与候选件真身实测（面索引见 §5），非估计。
> 纪律：先量后定；探针的区间可能误含紧随其后的构造函数（构造函数名不含类限定故不入函数表），**凡候选件均已读真身后再定序**。

## 1. 测度口径

- **体量**：逐件函数行数清点（探针）；构造函数相邻区间会误含，故候选件逐个读真身。
- **真判定口径**（承前轮）：有分支语义、可脱离 GUI 与 SDK 座化、行为零变更可钉；「类型 → 控件」这类映射表不判为真判定。
- **处置四类**：真核候选 / 虚档（无真核或核已在他面）/ 已收束 / 已立项。

## 2. 真核候选三族

### 2.1 ROI 交互判定族（最强，下一抽对象）

- **构成**：手柄命中（按形状分派手柄集 → 阈值命中 → 逐形状的「整体移动」判定：轴对齐矩形用外接框、旋转矩形用局部坐标、线段用投影距离、圆用半径内含）、手柄拖拽映射（手柄 → 形状更新，逐形状分支，含旋转角点与最小尺寸夹持）、以及坐标变换与旋转角点两个助手。
- **体量**：命中七十三行 ＋ 拖拽映射七十二行 ＋ 两个助手，族体约两百行。
- **纯度**：纯几何——只吃形状、点、缩放与偏移，无 GUI 无 SDK ⇒ **可座化**（纯几何断言，构造形状与点即可验）。
- **风险与口径**：形状类型与手柄枚举现住在显示窗头件内；抽取时**类型归属保持稳定**（类型可留原头件，新面只收判定），避免牵动读侧算子与标注窗。
- **与既有件的关系**：共享算子基类的 ROI 写回链（写回编组已在显示控制器）与异常检测节点的 ROI 读取相接；本族只收「手柄交互判定」这一段，**不碰写回链**。

### 2.2 场景夹具校验族

- **构成**：夹具名空值拒收（与写侧同一道闸）、位姿矩阵恰六项、逐项数值与有限性校验、不合形者**降级而非整条丢弃**（位姿坏一键不连累矩阵）并把降级原因回报。
- **体量**：校验段三十行起（降级与原因回报在同段内）。
- **纯度**：吃 JSON 与拒绝清单、产出校验后的夹具与原因 ⇒ **可座化**（纯数据判定 ＋ 原因文案）。
- **口径提醒**：写侧已有两道闸（拒空名、拒非六项），抽取须**两侧同口径**，不得新增第二套语义。

### 2.3 寄存器值换算族

- **构成**：类型分派（int16 / uint16 / int32 / uint32 / float）＋ 长度守卫 ＋ 统一大端解释（字节序归一化已在装配段完成）。
- **体量**：四十八行。
- **纯度**：纯字节换算，无 SDK 无 GUI ⇒ **可座化**。
- **口径提醒**：同族还有装配段的字节序归一化（与接收事件侧的取值口径同源）；抽取时须一并量明是否同族，避免拆成两套口径。

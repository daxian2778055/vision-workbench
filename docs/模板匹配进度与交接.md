## 四、铁律（每条都是踩过的坑）

1. **CI 运行期间禁止本地 `cmake --build`** —— 会抢同一构建目录导致 `LNK1104`（已发生 3 次）
2. **加参数必须同步面板槽位基准**（`param_panel_binding_test` 里的 `fieldSlots == N`，当前 284）
3. **`registerParams({...})` 插入要用"配对结尾"当锚** —— 用列表内某行的 `);` 会插到列表外（编译能过、不生效）
4. **登记表 md5 从 manifest 的 `exe md5` 行程序化提取**，不要手打
5. **先量后改**：改算法前先用真图腿量基线；改完不达标就回退（倒角→GOC、CLAHE 无效都走过这条路）
6. **Python 写文件带 `newline`**：该文件原本 LF 就写 LF、原本 CRLF 就写 CRLF，否则 EOL 闸会红
7. **B1 之后新增算子只准走 `HalconNode::addOutputPort`** —— 直接 `NodeBase::addOutputPort` 会绕开折叠，
   在画布上多出一个红点（`SingleOutputPortTest` 会红）
8. **逻辑子输出仍保留在旧键上**：`getOutputData(1..N)` 依旧能取到（老用例/脚本/旧插件依赖），
   但**接口上只有端口 0**；清输出必须用 `logicalOutputPortCount()`，不能用 `outputPorts().size()`
9. **验证新用例的命令**：`cd build && ctest -C Release -R <Name> --output-on-failure`；
   遍历注册表的用例需要 `dist/VisionFlowPlatform` 进 PATH（CMake 里已注入，缺了会 0xc0000135）

## 二、未对齐（按"用户感知强度"排序）

| 序 | 缺口 | 现状 | 落点与成本 |
|---|---|---|---|
| 1 | **多目标输出** | 只输出最优 1 个；`matchRow/Col/Score` 单值 | 需要把"粗搜+精修"包成 `findOne(foundList)` 并对已找到位置抑制，最多 N 个；输出 `matchCount` + `matchList`（"row,col,score"）；编辑器叠加多个框。**约 1 天**，动核心匹配块，必须带基准腿 |
| 2 | **训练向导** | 只有「训练模板」按钮，没有"框选→矫正预览→角度/尺度范围→质量评分"的引导流程 | 新对话框：① 框选模板区 ② 预览矫正后模板 ③ 设角度/尺度范围 ④ 训练并给出"模板角点丰富度/自匹配分数"评分。**约 1.5 天**，纯 UI + 复用现有训练路径 |
| 3 | **亚像素与稳定性** | 位置是整像素；结果无稳定性评分 | 精修后对峰值做抛物线插值（x/y 各一次）≈ 0.5 天；稳定性可用"峰值/次峰比"表示 |
| 4 | **掩膜参与匹配** | `paintMaskAt` 的掩膜只在执行时参与（`editMask`），模板匹配的评分未按掩膜降权 | 与 1 一起做更省（同一处 result 处理）≈ 0.5 天 |
| 5 | **多模板（一个工具多模板）** | 无 | 产品化需求，需数据模型改动，暂不做 |

## 三、方法选择建议（写进用户手册）

| method | 适用 | 注意 |
|---|---|---|
| 0 归一化平方差 | 亮度稳定的场合 | 对光照变化敏感 |
| 1 归一化相关系数（默认） | 通用 | 旋转插值+光照变化下分数会掉 |
| **2 倒角（边缘）** | 有清晰轮廓、光照会变、需要抗旋转插值 | **分数口径不同于 0/1**（1=完美贴合），`minScore` 要重新标定（建议 0.7 起试） |

## 四、本轮踩到的坑（留给下次）

1. **边沿图直接做 NCC 会塌分**（0.138）——位置对、分数假。形状匹配要用距离场。
2. **稀疏掩膜需要下限保护**：模板边沿点 < 16 个时直接判无效，否则距离场"处处为 0"会骗高分。
3. **粗到细的坐标必须无条件换算回全分辨率**（曾经只在精修更好时改写 → 位置偏 3 倍）。
4. **补丁脚本连跑两次会在 `registerParams({...});` 之后留游离副本**（能编译、不生效）→ 加参数后必须核对 `fieldSlots` 实测值。

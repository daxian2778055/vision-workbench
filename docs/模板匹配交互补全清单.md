# 模板匹配交互补全清单（2026-10-31）

> 背景：批 A（VM 手感地基）已交付（搜索区域 / 灰框候选 / 图形↔参数双向同步）。
> 现场试用后确认还有 5 项缺口。本文件是**执行清单**，按序推进，每项都要带可验证的读数。

## 需求（用户原话）

「训练模板」按钮 + 预览 + **运行时匹配渲染显示**都想显示出来；
另外缺少多边形、没有橡皮擦掩膜、右侧参数没看全（UI 布局缺陷）。

## 执行清单（按序）

### 1. 参数面板布局（UI 缺陷，最先修）
- **现象**：参数面板被截断；右侧数值框被裁（如 `2391.00` 少显示一位）
- **改法**：参数面板加滚动 + 数值列自适应宽度 + 右侧数值框最小宽度
- **验收**：`roiCenterCol=2391.00` 等长数值完整显示；窗口缩放不裁切

### 2. 橡皮擦 / 掩膜笔刷（半成品接上）
- **现象**：`HalconWindow::paintMaskAt` 已有，但 `setMaskBrushRadius` 在注释里自认"**实际上没有任何作用**"
- **改法**：笔刷半径接到 `paintMaskAt`；加擦除模式（切换按钮 / 右键）
- **验收**：涂抹/擦除都能改掩膜，半径调节生效

### 3. 「训练模板」按钮 + 训练后预览（用户点名）
- **现状**：训练是"勾选『从图像 ROI 训练并保存模板』后自动落盘"，**没有独立按钮**、训练后**无预览**
- **改法**：工具栏加「训练模板」按钮；训练完成立刻在画布渲染**矫正后的模板**与**匹配结果**
- **验收**：点按钮 → 出矫正模板 → 匹配结果框画在图上

### 4. 运行时匹配渲染（用户点名）
- **现状**：节点只输出 Measure，叠加层已支持 RotatedRect/Text/灰框候选
- **改法**：确保运行/重算后画布立即渲染命中框+分数、未命中灰框候选；与「自动重算」联动
- **验收**：改参数 → 自动重算 → 结果框实时更新

### 5. 多边形搜索区域（代码已备）
- **现状**：实现已完成（参数 + 包围盒预裁 + 候选掩膜），被 INV5 的**注册缺口**拦下并回退
- **改法**：先抓 INV5 明细（导出文件、去 ANSI）→ 补注册 → ELW 绿 → 提交
- **验收**：多边形搜索区域内能匹配、区域外不产生候选；矩形语义不变

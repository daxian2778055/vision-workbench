## 1. 目标与非目标

**目标**：运行中允许编辑拓扑；**当轮不受影响**（跑完自己的快照），**下一轮生效**；被删节点不崩、不泄漏。

**非目标（范围外，避免误解）**：
- 不追求"热替换正在执行中的那个节点"（当轮语义就是跑旧图）；
- 不改参数编辑现状（已支持）；
- 不做跨流程的事务性发布（多流程各自独立，沿用现有隔离）；
- 不引入新的编辑锁类型（只做"减法 + 语义明确"）。

| 5. `invalidateDownstreamOf` "查状态 → 清缓存"窄窗口 | ⏸ **明确不做**（后果有限：轮首剪枝兜底；单独立项收益低于引入的风险） | §7 |

**清单 4 的做法变更（重要，与本文件原方案不同）**：不在 GUI 槽内直接清缓存。
原方案会让 GUI 侧去取图锁，与执行线程"图锁内再触碰节点/场景"的既有路径构成
"GUI：场景锁 → 图锁" vs "执行：图锁 → 节点/场景锁"的**锁环**——首次尝试即在 ctest 下挂起、整段撤销。
改成 **"GUI 只登记（叶子锁 `m_purgeMutex`）→ 执行线程在安全点消费"**
（安全点：`run()` 轮首 + `executeUpTo` / `executeFrom`）。环从结构上不存在，不依赖时序运气。
登记项里的裸指针**只作 map 键**使用（节点可能已被立即析构），模块号在登记时取好。
副作用（已知且可接受）：清理延迟到安全点，极端情况下"已删节点的条目"会被多留一小会儿，
后果只是下游多算一次（保守方向），不会读到旧值。

**验收**：全量门禁绿（每次提交前实测）＋ 并发/压测用例 ✅ ＋ **新增回归钉子**
`testNodeChurnDuringContinuousRun`（连续模式 + 高频增删节点，**默认运行**）。
**反证不是空转**：Stage 1 期间的真实反证——加锁后的首次尝试**确实**在 ctest 下挂起，
缺陷已定位并修复（见 §9）；另有一次门禁以编译失败拦下提交（未提交即返工）。

## 9. 附录：Stage 1 期间定位并修复的既有缺陷（自死锁）

**现象**：连续模式下，停止请求若落在"轮内"，`stopExecution()` 后 worker **永不退出**
（`exec.wait(5000)` 失败、进程随后无法退出 ⇒ 停止 / 关窗都卡住）。

**定位链（三层证据，非推测）**：
1. **用例复现**：新增压测段 `testNodeChurnDuringContinuousRun`（连续模式 + 1.5s 高频增删节点）稳定复现；
2. **A/B 对照**（判归属）：B = 含当时改动 → 挂起，且 3–6s 内 **CPU 增量 0s**（=阻塞，非空转）；
   A = 基线（只 stash 改动、保留用例）→ **同样挂起** ⇒ 与那批改动无关，属**既有缺陷**；
3. **阶段诊断探针**（新增 `workerPhaseName()`：执行线程在关键点写 relaxed 原子、任意线程可读）
   连续 12 次采样（3 秒）全部停在同一处 → 逐步细化到 **"轮末：信号后（节拍/回转）"**
   ⇒ 已发完 `executionFinished()`，却进不了下一轮。

**根因**：`run()` 节点循环以 `locker.relock()` 持有 `m_mutex`，两处 `if (m_state == Stopped)`
**持锁 `break`** 跳出；随后轮末与循环尾的 `QMutexLocker ml(&m_mutex)` 再对**同一把非递归锁**加锁
⇒ **自死锁**。触发条件是"停止请求落在轮内"（软触发单轮结束后再停不走这条路径，故长期未暴露；
连续模式 + 运行期改图的时序把它稳定暴露出来）。

**修复**：两处 `break` 前 `locker.unlock()`（**先解锁，再** `emit executionStopped()`）。

**验证**：开关版压测从"挂起 60s 被强杀"变为 **PASS / 约 1.6s / exit=0**；压测段恢复默认运行且 ×3 全过；
全量门禁绿（integration 43 passed / 0 failed / 2 skipped、comm 44/44、ctest 14/14）。

**方法论留档**（下次遇挂起类问题照此办）：
1. 先看 **CPU 增量**：0 = 阻塞（锁/等待），持续增长 = 空转；
2. 无栈可看时用**阶段探针**取代猜测（原子变量记录"走到哪一步"，可在挂起时安全轮询）；
3. 归属用 **A/B 对照**（stash 改动跑基线），避免把既有缺陷记账到本轮改动上；
4. 结论写进提交说明与本文档，探针保留为现场诊断手段。

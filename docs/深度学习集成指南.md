# 深度学习集成指南（HALCON DL 与 OpenCV DNN）

本平台**只做推理，不做训练**：模型在外部训练（Ultralytics / PyTorch 等）后导出为 ONNX 或 HALCON DL 模型，
再在流程图里用对应算子加载。**全程离线**（模型文件需在本地），无任何在线下载/联网校验。

---

## 1. 能力与算子对照

| 任务 | 算子（注册名） | 输入输出要点 |
|---|---|---|
| 分类（ONNX） | `ONNX深度学习推理`（`DnnInferNode`） | 图像 → 类别 + 置信度（含 top-K） |
| 分类（OpenCV ML） | `分类推理`（`OpencvClassifyNode`）／`分类器训练`（`OpencvTrainClassifierNode`） | 训练产物为本地文件，训练/推理均可离线 |
| 目标检测（YOLO 系列） | `ONNX目标检测`（`DnnDetectNode`） | 兼容 v5 `[1,N,C]` 与 v8 `[1,C,N]` 布局；NMS；输出框+类别+置信度+带框图 |
| **分割**（语义 / 实例） | `ONNX分割`（`DnnSegmentNode`） | 语义 `[1,C,H,W]`；实例 YOLO-Seg 双输出；输出掩膜图像/面积/数量/目标框/叠加图 |
| OCR（传统） | `ZXing条码解码` / `二维码解码` / `TesseractOCR` | 语言数据随包 `tessdata/` |
| OCR（深度） | `DeepOCR`（`DeepOcrNode`） | HALCON DL 模型，本地加载 |

## 2. 模型准备（外部训练 → 导出 ONNX）

- 检测：Ultralytics YOLO 系列导出 ONNX；类别名可放在模型同目录 `classes.txt`（或用 `classNamesPath` 指定）。
- 分割：
  - **语义分割**（UNet / DeepLab / FCN）：输出 `[1, C, H, W]`。`C == 1` 走"单通道 + 阈值"，`C >= 2` 走"逐像素 argmax = 前景类"。
  - **实例分割**（YOLO-Seg v8/v11-seg）：双输出 `[1, 4+numClasses+K, N]`（框 + 类分数 + K 个掩膜系数）与
    `[1, K, mh, mw]`（掩膜原型）；节点自动识别该形态。
- 预处理保持一致：平台默认 `scale = 1/255`、`mean = 0,0,0`、`swapRB = 开`（与 Ultralytics 一致）；
  若你的训练用了不同归一化，请在节点参数里对齐，否则精度会明显下降。

## 3. 三个实测陷阱（都已在代码/用例里钉住，勿凭直觉改）

1. **二次 sigmoid**（分割 · 单通道）：不少导出的 ONNX **图内已含 Sigmoid**（输出即概率，值域 `[0,1]`）。
   若再压一次：`sigmoid(x) > 0.5 ⟺ x > 0`，而概率背景恰好 = 0.5 → 判据恒真，**整幅图都变前景**
   （实测：应 486 px 的掩膜变成 4096 px，且**不报任何错**）。
   处置：`sigmoidMode` 为三态 —— **自动（默认）**/强制开/强制关；"自动"按值域是否越出 `[0,1]` 判断模型是否已内置。
   结果面板的 `sigmoidApplied` 显示本次实际取值。
2. **letterbox 灰边污染**（分割 · 保比例模式）：灰边会被模型当成前景，卷积还会把这份前景**向有效区内扩一个感受野宽度**；
   "裁掉灰边"只能去掉灰边本身，去不掉这条贯通整幅的假前景带（实测 96×64 图片：掩膜外接框被撑成整幅、面积 866 而非 484，
   现场表现是"图像上下边缘各一条假缺陷带"）。
   处置：**默认 `keepRatio = false`（拉伸）**；确需保比例时把 `paddingValue` 设为训练时的填充值，
   并用 `padTrim`（默认 1，深网络调大）清理污染带。
3. **概率边界噪点**：概率输出在 0.5 边界的浮点误差会留下离散前景点（实测连通域 3 个而非 1 个）。
   处置：用 `minArea` 过滤小连通域（掩膜/面积/数量/框会一起保持一致）。

## 4. 分割算子参数速查（`ONNX分割`）

| 参数 | 默认 | 说明 |
|---|---|---|
| `modelPath` | 空 | ONNX 模型路径（必需） |
| `segMode` | 自动 | 自动 / 语义分割 / 实例分割(YOLO-Seg) |
| `inputWidth` / `inputHeight` | 640 / 640 | 网络输入尺寸 |
| `keepRatio` | **关** | 关 = 拉伸（无灰边、几何精确）；开 = letterbox（务必配 `padTrim`） |
| `paddingValue` | 114 | letterbox 灰边灰度（应与训练时一致） |
| `padTrim` | 1 | 清理紧邻灰边的污染带宽度（网络输入空间像素） |
| `classIndex` | 1 | 语义多类：argmax 等于它即前景 |
| `binaryThresh` / `sigmoidMode` | 0.5 / 自动 | 单通道语义二值化 |
| `confThresh` / `nmsThresh` | 0.25 / 0.45 | 实例模式 |
| `minArea` | 0 | 最小连通域面积（低于则从掩膜剔除） |

输出端口：**掩膜图像**（8U 0/255、原图尺寸，主输出端口）/ 面积 / 数量 / 目标框数组 / 图像(叠加)。
说明：按本仓纪律**不输出 HALCON 区域端口**（替换版环境区域算子有跨进程反转实证），掩膜走图像域，
下游可接 `形态学`（去噪）、`Blob分析`（连通域/面积）等既有节点。

## 5. 排查

| 症状 | 处置 |
|---|---|
| 模型加载失败 | 确认 `modelPath` 指向本地 .onnx；平台不提供在线下载 |
| 掩膜整幅都亮 | 见第 3.1 节：把 `sigmoidMode` 设为"强制关"或保持"自动" |
| 掩膜在图像边缘出现贯通亮带 | 见第 3.2 节：改用拉伸（`keepRatio` 关）或调大 `padTrim` |
| 检测/分割结果类别名是数字 | 提供 `classes.txt` 或设置 `classNamesPath` |
| 精度明显不达预期 | 先对齐预处理（`mean`/`scale`/`swapRB`/`keepRatio`）与网络输入尺寸，再看模型本身 |

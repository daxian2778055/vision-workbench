# YOLO 检测 / 流水线计数 · 上线手册

> 适用：`DnnDetectNode`（单帧检测）、`ObjectCountingNode`（流水线过线计数）
> 最后更新：2026-10-28

## 0. 一句话说清边界

| 环节 | 谁做 | 我们的软件 |
|---|---|---|
| 标注（画框+类别） | **外部工具** | ❌ 不做（我们的标注/训练是"分类"那一套） |
| YOLO 训练 | **外部（Ultralytics）** | ❌ 不做 |
| 导出 ONNX | 外部 | ❌ 不做 |
| **推理（检测）** | — | ✅ `DnnDetectNode` |
| **跟踪 + 过线计数** | — | ✅ `ObjectCountingNode` |

所以"全套"是：**外部标注训练 + 我们推理计数**。想让训练也进软件，是下一阶段的事（要做检测标注器 + 训练编排）。

## 1. 外部三步（一次性，每个料号）

```bash
# ① 标注：LabelImg / Label Studio / Roboflow，导出 YOLO 格式（images/ labels/ data.yaml）
# ② 训练
yolo detect train data=data.yaml model=yolov8n.pt epochs=100 imgsz=640 batch=16
# ③ 导出 ONNX（imgsz 与节点里的"网络输入尺寸"一致）
yolo export model=runs/detect/train/weights/best.pt format=onnx imgsz=640 opset=12
```

产出两份文件：
- `best.onnx`
- `classes.txt`（**每行一个类名，顺序必须与训练时一致**）

## 2. 在我们软件里配置

### 2.1 单帧检测（`ONNX目标检测`）
| 参数 | 说明 |
|---|---|
| 模型路径 | `best.onnx` |
| 类别名文件 | `classes.txt`（留空则取模型同目录的 classes.txt） |
| 网络输入尺寸 | **必须与导出时的 imgsz 一致**（不一致时框会整体缩放错位） |
| 置信度 / NMS | 起手 0.25 / 0.45，漏检多就降置信度，重复框多就降 NMS |
| 推理后端 | CPU / OpenCL（GPU）。OpenCL 不可用时 OpenCV 会静默回退，以实测帧率为准 |

输出：①检测框 ②数量 ③带框图

### 2.2 流水线计数（`流水线计数`）
在检测参数之外多这些：

| 参数 | 说明 | 现场经验 |
|---|---|---|
| 计数线 A/B 点 | 画面上一条线，**垂直于物料流向** | 线要覆盖物料实际经过的通道宽度 |
| 计数方向 | 双向 / A→B 侧 / B→A 侧 | 只数一个方向时选单侧，能挡掉回流误计 |
| 确认所需帧数 | 目标要连续出现多少帧才认 | 30fps 下 3 帧≈0.1s；抖动大就调到 5 |
| 允许连续漏检帧数 | 漏检多少帧后丢弃轨迹 | 遮挡/反光多就调大（15 帧≈0.5s） |
| 推理后端 | 同上 | — |
| 下一次运行前清零 | 置 true 跑一次即清零并自动复位 | 换批次/换料时用 |

输出：①标注图（框+ID+计数线+`count=N (+本帧)`）②**累计数** ③JSON（总数/本帧新增/按类/事件）

## 3. 上线前必须验的六件事

1. **类别名对齐**：故意删掉 `classes.txt` 一行 → 节点应报"模型输出 N 类，classes.txt 只有 M 行"，不能默默给数字
2. **输入尺寸对齐**：用 640 导出的模型配 320 输入 → 框会缩到左上角，属配置错不是算法错
3. **计数不重复**：让同一个物体在线上来回走 → 只计一次；反向再走回来 → 按方向设置决定是否计
4. **遮挡不断号**：用手挡 0.3s 再放开 → ID 不变、不新增计数
5. **节拍**：实测单帧耗时（性能面板），低于产线节拍才可上；不够就切 OpenCL / 换小模型（yolov8n）
6. **换批次清零**：触发一次 `resetCounter`，确认累计归零且下一次不再自动清零

## 4. 常见故障对照

| 现象 | 最可能原因 |
|---|---|
| 一个框都没有 | 置信度太高 / 模型与类别不匹配 / 输入尺寸不一致 |
| 框位置整体偏移或缩放 | `imgsz` 与"网络输入尺寸"不一致 |
| 同一物体被计两次 | 跟踪器丢 ID（`允许漏检帧数` 太小、或帧率太低导致位移超过 IOU 门限） |
| 计数偏少 | 目标压线时 `确认所需帧数` 未满足、或计数线不垂直于流向 |
| 帧率很低 | 走 CPU：切 OpenCL；仍不够则缩模型/降输入尺寸 |
| 类别全显示数字 | `classes.txt` 缺失或行数与模型不符（节点会在 `countNote` 里点名） |

## 5. 与"分类训练"的分工

| 需求 | 用哪个 |
|---|---|
| "这是 A 类还是 B 类"（整图/剪裁） | 训练向导 + 分类推理（ANN_MLP，软件内可完成） |
| "图里有几个、在哪、过的多少个" | YOLO（外部训练）+ 检测/计数节点 |

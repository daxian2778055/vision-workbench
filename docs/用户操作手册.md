## 1. 软件概述

VisionFlowPlatform 是一款对标海康 VisionMaster 4.4 的机器视觉流程开发平台，采用**流程编辑**方式搭建视觉方案：

- **算子（工具）**：以节点形式拖入画布，配置参数后按数据流连接
- **流程**：节点按连线顺序执行，图像与数据沿连线传播
- **方案**：整套流程保存为 `.vfp` 文件（JSON 格式），可随时加载复用

核心特性：

| 特性 | 说明 |
|------|------|
| 图像算法 | OpenCV（二值化、形态学、Blob、边缘、拟合、卡尺、模板匹配、缺陷、标定等） |
| 图容器 / DeepOCR | HALCON 24.11（读图、显示、HALCON DeepOCR） |
| 多流程 | 支持多标签页并行编辑多个流程 |
| 自定义 HMI | 运行界面设计器，拖拽式搭建现场操作界面 |
| 数据管理 | 全局变量、配方、结果数据库、操作日志、通信监视 |
| 用户权限 | 管理员/操作员分级登录 |

## 2. 运行环境与安装

### 2.1 硬件要求

- CPU：x64，建议 4 核以上（深度学习推理建议独显 + 6 核）
- 内存：8 GB 以上（500 万像素相机建议 16 GB）
- 存储：安装包约 500 MB，数据目录建议预留 10 GB

### 2.2 软件依赖

| 组件 | 说明 |
|------|------|
| Windows 10/11 x64 | 操作系统 |
| HALCON 24.11 | 读图、显示、DeepOCR 需要运行时与 License（详见 13.3） |
| OpenCV | 4.13.0（thirdparty/ 目录；日常图像算法与相机标定） |
| MVS（可选） | 使用海康相机时需要 MVS 运行时 |

### 2.3 安装

1. 将部署包（见 13.1）解压到目标机任意目录（建议 `C:\VisionFlowPlatform`）
2. 配置 HALCON License（见 13.3）
3. 双击 `VisionFlowPlatform.exe` 启动
4. 首次启动需**创建初始管理员账号**（用户名 + 密码≥6 位，无默认口令）

### 2.4 启动自检

启动不再拦截区域/测量自检。日常算法走 OpenCV，不依赖 HALCON 区域链路。需要时用菜单 **帮助 → HALCON 图像层自检** 检查读图/显示是否可用。方案含 **HALCON DeepOCR** 或 **Halcon图像源** 时会提示确认 HALCON 运行时。

## 3. 快速上手（5 分钟搭建第一个方案）

以"读取图像 → 二值化 → Blob 分析 → 显示"为例：

1. **新建方案**：菜单 `文件 → 新建`（或 Ctrl+N）
2. **添加读取图像算子**：左侧工具库 → `图像采集` 分组 → 双击或拖拽 **读取图像** 到画布
3. **配置参数**：选中节点 → 右侧参数面板 → 点击"浏览"选择一张测试图片
4. **添加处理算子**：拖入 **二值化**（图像处理分组）→ 参数面板设置模式与阈值
5. **添加 Blob 分析**：拖入 **Blob分析** → 设置最小面积
6. **连线**：从读取图像输出端口（右侧小圆点）按住拖到二值化输入端口 → 二值化输出连到 Blob 输入
7. **添加显示**：拖入 **显示** 算子，连接到 Blob 输出
8. **运行**：点击工具栏 **单次执行**（或 F5 软触发模式启动）
9. **查看结果**：主图像区自动显示最后一个算子图像；选中节点可查看其输出；状态栏显示状态/耗时/触发计数

> 提示：测量类算子（线段查找/圆查找/卡尺）参数面板有 **"在画布上设置搜索区域"** 按钮——点击后在图像上拖拽绘制搜索线/圆，松手自动写回坐标。

├──────────┼──────────────────────────┼──────────────┤

| 区域 | 功能 |
|------|------|
| 工具库 | 按分组（图像采集/图像处理/特征定位/几何测量/识别/标定/逻辑/输出/深度学习）浏览算子；顶部搜索框过滤 |
| 流程编辑区 | 拖拽/双击创建节点，画布 20px 网格，多标签页 |
| 图像显示区 | 显示算子输出图像；工具栏：适应窗口/100%/放大/缩小/十字线/保存图像；滚轮缩放、拖动平移 |

**帮助**：菜单栏“帮助 → 使用手册”（或按 F1）在软件内打开本手册；手册文件位于程序目录 `docs/用户操作手册.md`，现场可直接替换更新。

## 5. 方案管理

| 操作 | 方式 |
|------|------|
| 新建方案 | 菜单 文件→新建（Ctrl+N），创建空流程 |
| 打开方案 | 菜单 文件→打开方案（Ctrl+O），选择 `.vfp` 文件 |
| 保存方案 | 菜单 文件→保存方案（Ctrl+S）；未指定路径时弹出保存对话框（自动补 `.vfp` 后缀） |
| 最近打开 | 文件菜单 → 最近打开（最多 8 条，可清空） |
| 多流程 | 流程标签页右侧"+"添加流程；标签页右键关闭 |

方案文件包含：全部流程的节点/连线/参数/布局，以及**全局配置**（全局变量、相机配置、通信配置、全局触发、心跳配置）。换机迁移时直接拷贝 `.vfp` 即可。

### 5.1 自动保存与崩溃恢复

| 场景 | 软件行为 |
|------|----------|
| 编辑中（默认每 60 秒检查一次） | 有未保存改动时写一份恢复文件，状态栏提示"已自动保存（异常退出后可恢复）"；**内容没变则不写盘** |
| 上次**异常退出**（断电 / 崩溃 / 强杀进程） | 下次启动弹出「崩溃恢复」：**恢复**＝把自动保存内容加载到界面；**丢弃**＝删除该文件 |
| 正常关闭、且没有未保存改动 | 恢复文件被清除，下次启动不会打扰（刚装完的空方案也不会弹提示） |
| 正常关闭、但**有**未保存改动 | 弹出「退出前确认」：**保存并退出 / 不保存退出 / 取消**（取消则继续编辑） |
| **打开方案 / 新建方案**前 | 若当前方案有未保存改动，先弹「未保存的修改」：**保存并继续 / 不保存继续 / 取消**（取消则不切换、不新建） |

- **恢复文件位置**：软件目录下 `data/recovery/recovery.vfp`（安装目录不可写时自动回落到用户数据目录，
  日志里会打印实际路径）。
- **手工找回**：恢复文件本身就是合法的方案文件，可直接用 文件→打开方案 打开它。
- **恢复后请保存**：恢复出来的内容还没有写回原方案文件，界面恢复后请确认后用「保存方案」写回
  （若直接关窗，仍会弹「退出前确认」）。
- **可配置项**（软件配置，`recovery/` 前缀）：`autoSaveIntervalSec` 自动保存间隔秒数（默认 60，
  置 0 关闭自动保存）、`promptOnClose` 关闭软件 / 打开方案 / 新建方案前是否提示未保存修改（默认提示）、
  `promptOnStartup` 启动是否询问恢复（默认询问）。环境若禁用配置写入，这些项保持默认值，
  **不影响恢复功能本身**。

## 6. 流程搭建操作

### 6.1 节点操作

| 操作 | 方法 |
|------|------|
| 添加节点 | 工具库拖拽或双击 |
| 移动节点 | 拖动；连线自动跟随 |
| 选中 | 单击（高亮）；空白处单击取消 |
| 删除节点 | 右键 → 删除（连带删除关联连线） |
| 复制节点 | 右键 → 复制（含参数，副本偏移 30px） |
| 禁用/启用 | 右键 → 禁用（灰色，运行时跳过并透传） |
| 重命名 | 右键 → 重命名（影响完整名称，用于运行界面绑定） |

### 6.2 连线

- 从**输出端口**（节点右侧圆点）拖到**输入端口**（左侧圆点）
- 端口类型不匹配时拒绝连接并提示（日志区可见）
- 输入端口已连接时需先断开（右键连线 → 删除）
- 连线删除：右键连线 → 删除连线

### 6.3 撤销/重做

- Ctrl+Z 撤销、Ctrl+Y 重做（深度 50 步）
- 覆盖：节点添加/删除/复制/移动、连线添加/删除

### 6.4 画布 ROI 取点（测量类算子）

线段查找 / 圆查找 / 卡尺的参数面板 → **"在画布上设置搜索区域"**：

1. 点击按钮（需图像区已有图像）
2. 在图像上按住左键拖拽绘制搜索线（或圆）
3. 松手后坐标自动写回参数面板（右键取消）

### 6.5 算子分组（Group）

把一堆算子框成一组，便于阅读与整体搬移（**纯视觉容器，不影响执行**）。

| 操作 | 方式 |
|------|------|
| 创建分组 | 先框选 ≥2 个算子 → 画布空白处右键「创建分组（N 个算子）」或 编辑 → 创建分组（**Ctrl+G**） |
| 整体搬移 | 拖动**分组标题栏**（组内其余区域仍可框选/点击算子，不会被分组吃掉） |
| **折叠 / 展开** | **双击分组标题栏**，或右键分组 →「折叠/展开分组」，或 编辑 → 折叠/展开分组。折叠后组内算子与相关连线隐藏，框体收成一条标题栏（标着"已折叠"与算子个数） |
| 改名 | 右键分组 →「重命名分组…」 |
| 选中组内算子 | 右键分组 →「选中组内算子」（分组处于折叠状态时会先自动展开，避免选中看不见的算子） |
| 解散分组 | 选中分组框后按 **Delete**、或 编辑 → 解散分组（**Ctrl+Shift+G**）、或右键分组 →「解散分组（保留算子）」 |

- 分组随方案一起保存（换机拷贝 `.vfp` 即带走）；撤销/重做也会带上分组。
- 拖动组内某个算子后，分组框会自动收拢/长大；把成员算子删光时，分组自动解散。
- **注意**：分组**不参与执行**——它不改变流程的跑法与结果，只是画布上的组织方式。
  需要"把一段流程当作可复用的子流程调用"是另一项能力（FR15.10），当前**未实现**。
- **折叠是纯显示**：不影响流程执行，状态随方案一起保存（重开方案仍保持折叠）；**解散分组后组内算子一定恢复可见**。
- 折叠大段流程后画布更清爽：折叠框的**宽度**保留（一眼看出被收起的那段有多宽），位置不变。
- 编辑锁定（连续模式运行中）时不能创建/解散/拖动分组，与算子编辑锁定一致；但**折叠/展开仍可用**（查看动作）。

### 6.6 复制/粘贴与片段导入导出（子图复用）

把**一段流程**（多个算子 + 它们之间的连线）整段搬到别处，不用手工重连。

| 操作 | 方式 |
|------|------|
| 复制所选算子 | 画布上框选算子后按 **Ctrl+C**（画布需有焦点，点一下画布即可），或 编辑 → 复制所选算子 |
| 粘贴 | 按 **Ctrl+V**，或 编辑 → 粘贴。片段会落在**当前视图中心**并自动选中，方便直接拖走 |
| 导出片段文件 | 编辑 → 导出片段…，存成 `.vfseg`（普通 JSON 文本，可进邮件/工单） |
| 导入片段 | 编辑 → 导入片段…，插入到当前流程的视图中心 |

- **随片段带走的**：这些算子的全部参数、**两端都在选中范围内**的连线、以及完全落在选中范围内的分组框。
- **不会带走的**：跨出选区的连线（对端不在片段里，无法对应）。复制时会提示"**N 条跨边界的连线未包含**"——
  粘贴后请手动补连。
- 粘贴/导入时：算子的**模块号会重新分配**（避免与目标方案里的号撞车），**重名的算子自动加 `_2` 后缀**
  （变量引用按算子名定位，撞名会让引用指向不确定）。
- **一次粘贴 = 一次撤销**（Ctrl+Z 可整体撤回）。
- 与"子流程"的区别：这是**拷贝一份出来**（改一处不会同步到别处）。"把一段流程当算子调用"（改一处、处处生效）
  属另一项能力，**当前未实现**（设计草案见 `docs/子流程复用设计草案.md`）。

### 7.4 特征定位

| 工具 | 用途 | 关键参数 |
|------|------|---------|
| Blob分析 | 连通域提取与面积过滤 | 最小/最大面积；输出区域与区域数 |

| 缺陷检测 | 黄金模板差影 | 模板、阈值、形态学、最小面积 |
| 异常检测 | OK 样本建模，无监督检出未预见过的外观异常并输出热图 | 建模后端（统计基线 / PCA 残差）、教学模式、基线文件、判定倍数、σ 下限、最小/最大异常面积、NG 面积阈值、输出图像形式、对齐归一化 |
| 角点检测 | 角点提取 | 类型、阈值 |
| 相机标定 | 棋盘格内参标定 | 内角数、方格尺寸、多帧采集 |

#### 7.4.1 异常检测：怎么用，以及和「缺陷检测」怎么分工

**分工**：缺陷检测是**有标准件**的比对（拿一张黄金模板逐像素对，差出来就是缺陷）；异常检测是**只有 OK 件**的建模（用一批良品建出"正常长什么样"，凡不像的全算异常）。因此现场不必事先知道缺陷长什么样，但也因此**分不清"是缺陷还是良品摆歪了"**——划痕、脏污、位置偏移都会报出来，务必先看画面上的热图确认口径。

**教学**：`教学模式` 三选一——「覆盖式教学」以当前图重建模型（清空旧基线），「累加教学」把当前图并进现有模型（适合分批补样），「只推理」用已装载的模型判定。`基线文件` 留空则模型只在内存里，**重启即失**；要长期用必须填路径（教学成功后自动写入，只推理时按该路径装载）。在画布上拖一个矩形 ROI，参数会自动切到「累加教学」并开始攒样本。

**两个后端**（`建模后端`）不是新旧关系，各有盲区：

| 后端 | 原理 | 什么时候用 |
|---|---|---|
| 统计基线（逐像素 μ/σ） | 逐像素累积均值与方差，按偏离几个 σ 打分 | 位置稳定、要看小面积点状缺陷；一帧也能出模型 |
| PCA 残差（整体流形） | 每帧压成向量，只用 OK 批次的主要变化方向重构，**重构不掉的部分**算异常 | 良品本身逐件在变（光照/增益漂移等），逐像素 σ 被这种漂移撑大、小缺陷被淹掉时 |

PCA 相关参数：`PCA 主成分数`（保留多少个 OK 变化方向）、`PCA 分析尺寸长边上限`（建模前把 ROI 等比缩到该长边内，越大越慢越占内存、也检得越细）。

**三条必须知道的口径**：

- **模型文件不通用**：统计基线与 PCA 模型是两种格式。拿错文件直接报错并说明该选哪个后端，不会"将就着判"。
- **尺寸不符必报错**：待检 ROI 尺寸与模型不一致时报可见错误，**不会偷偷 resize**（那会把"换了产品忘了重新教学"变成"看着在工作、判定结果却没有意义"）。换产品或换 ROI 都要重新教学。
- **热图与判定是同一把尺子**：分数含义都是"偏离几个 σ"，`判定倍数` 就是二值化门槛；热图按同一个倍数定标（门槛处为分界色），所以"图上发红的地方"与"报出来的异常区"是同一批像素。`σ 下限` 兜住平坦区（σ≈0 时分数会爆），否则一片背景就能刷满红，而这种假阳调门槛救不回来。

`输出图像形式` 可选纯热图 / 热图叠加原图 / 原图+异常框。除图像外还输出异常数量、异常总面积、分数峰值与均值、样本数，以及「异常」数值端口（`x y w h` 四元组数组，与缺陷检测同口径）。

## 8. 运行控制

### 8.1 运行模式

工具栏"流程模式"下拉框：

| 模式 | 行为 |
|------|------|
| 软触发 | 点击"开始执行"（F5）运行一轮后停止；"单次执行"按钮等效 |
| 连续 | 点击"开始执行"后循环运行，直到点击"停止"（Shift+F5） |

### 8.2 单步执行

工具栏"单步"按钮：逐节点运行，每执行一个算子后暂停；再次点击推进下一个节点。配合节点颜色（绿=成功、红=失败、灰=禁用）排查流程。

### 8.3 状态栏

- **状态**：空闲/运行中/已停止/错误
- **耗时**：最近一轮完整流程耗时（ms）
- **触发**：累计触发轮数

### 8.4 编辑锁定

运行期间画布自动锁定（节点不可移动/编辑），停止后解锁。

### 9.1 良率目标与报警（统计报表）

- 打开 **视图 → 统计报表**，在顶部「良率目标(%)」填目标良率（**0 = 不设目标**）。
- 设了目标后：图表里多一条**目标虚线**（在「按天良率（%）」图上），KPI 显示**达标/未达标**（未达标标红），
  导出的 CSV / HTML 报告也带上目标与结论。
- **连续生产时会自动盯着**：按**最近 N 轮**（默认 50 轮，至少 10 轮才开始判）算良率，
  低于目标 → **报警**（状态栏 + 运行日志 + **系统 → 报警历史** 里一条 Warning）；
  恢复到目标线以上 → 给一条 Info 通知。
- 同一段低良率**只报一次**，恢复后才可能再报（避免刷屏把报警历史灌满）。
- 报警判定与报表用的是**同一批数据、同一口径**：报表里看到 98% 就一定不会报警，看到 97% 且目标 98% 就该报。
- 不想要报警：把目标设回 **0**。

## 14. 故障排查

| 现象 | 排查 |
|------|------|
| 加载方案提示「HALCON 运行时」 | 方案含 DeepOCR 或 Halcon图像源，确认本机 HALCON 可用于读图/OCR |
| 找不到「阈值 / OpenCV二值化」 | 工具库现名是 **二值化**；旧方案仍按别名加载 |
| Blob 无区域 | 二值化阈值、最小面积、输入是否为二值图 |
| 相机不出图 | MVS 客户端能否枚举 → 相机配置界面参数 → 触发模式（硬触发需外部信号） |
| 通信不生效 | 通信管理设备状态、监视窗口看收发、发送节点设备名是否匹配 |
| 崩溃 | logs/crash.log + logs/crash.dmp（minidump，用 VS/WinDbg 分析） |
| 想恢复误删 | Ctrl+Z 撤销（最多 50 步） |
